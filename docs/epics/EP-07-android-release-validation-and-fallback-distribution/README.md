# EP-07 Android release validation and fallback distribution

Status: `proposed`

Objective: Definire il backlog minimo per pubblicare, verificare e, se necessario, sostituire con un fallback controllato il rilascio Android dell'applicazione.

Tasks:

- `T-01` Publish the hosted HTTPS PWA release procedure.
- `T-02` Verify Android install, relaunch, and offline behavior from the deployed artifact.
- `T-03` Define the wrapper fallback decision gate if hosted PWA deployment remains blocked.
