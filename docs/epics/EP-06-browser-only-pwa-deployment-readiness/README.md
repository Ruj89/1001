# EP-06 Browser-only PWA deployment readiness

Status: `proposed`

Objective: Definire il backlog minimo per trasformare il runtime attuale in una PWA browser-only pubblicabile via HTTPS, senza dipendenze da server locale per il flusso Android target.

Tasks:

- `T-01` Define the supported deployment contract and release acceptance outputs.
- `T-02` Remove local HTTP runtime dependencies from the PWA path.
- `T-03` Align static assets, local persistence boot, and installability requirements for hosted release.
